# PROBLEM.md

Challenge context for this repo. Source: DEV Hacktoberfest Open-Source AI Challenge, Week 1.

## Dates

- Start: October 5, 2026
- **Submissions due: October 11, 2026, 11:59 PM PDT**
- Winners announced: week of October 12

## Prompt: Touch Grass

Build a new project with open-source AI at its core: an open-weight model, an open-source agent framework, local inference, or a mix. The open pieces must be what makes the project work.

Theme: get people off the screen and outside (hiking, gardening, birding, run clubs, foliage). The screen should be the shortest part of the experience. Bonus points for actually taking it outside, using it, and reporting how it went.

## The post must cover

- What we built and how it gets people outside
- A demo
- Why open innovation matters for this project: offline use, data staying on device, ability to swap or tune models, zero running cost, and where open beat closed
- Required tags: `#devchallenge`, `#hf26challenge` (added by the submission template)
- Optional but encouraged: agent session saved with DevRelay, embedded or linked
- Credit any non-trivial prior work or open-source code used

## Judging

1. Writing quality (weighted most heavily)
2. Relevance to prompt and theme
3. Creativity
4. Technical execution
5. Use of partner technology (optional)
